# 🖼️ AI-Based Image Color Compression

An ML-based image color compression system that uses **K-Means Clustering** to reduce the number of colors in an image while preserving its visual quality.

The project provides an interactive **Streamlit web application** where users can upload an image, select the desired number of colors, compress the image, analyze image quality, visualize the generated color palette, and download the compressed image.

## 📌 Project Overview

Digital images can contain thousands or millions of different colors. Many of these colors are visually similar and can be represented using a smaller set of representative colors.

This project treats every pixel as an RGB data point:

```text
Pixel = [R, G, B]
```

K-Means clustering groups similar RGB pixels into clusters.

The centroid of each cluster becomes a representative color.

For example:

```text
Original Image
Millions of possible colors
          ↓
      K-Means
          ↓
256 representative colors
          ↓
64 representative colors
          ↓
16 representative colors
```

The result is a visually similar image using significantly fewer colors.

# 🧠 Machine Learning Technique

## K-Means Clustering

K-Means is an **unsupervised machine learning algorithm** that divides data points into K clusters.

In this project, every image pixel is represented as an RGB vector:

```text
[R, G, B]
```

For example:

```text
[255, 0, 0]      → Red
[254, 2, 1]      → Similar Red
[0, 255, 0]      → Green
[0, 0, 255]      → Blue
```

K-Means groups similar colors together.

### Process

```text
              Input Image
                   ↓
          Convert to RGB pixels
                   ↓
             Pixel Matrix
                   ↓
        Sample pixels for training
                   ↓
             K-Means Clustering
                   ↓
          Find Color Centroids
                   ↓
       Assign every pixel to nearest
             color centroid
                   ↓
          Reconstruct Image
                   ↓
        Compressed Color Image
```

---

# 🔬 How K-Means Works

Suppose the user selects:

```text
K = 16
```

The algorithm finds 16 representative colors.

Each pixel is assigned to the closest representative color.

Conceptually:

```text
Original Pixel
     ↓
Find nearest centroid
     ↓
Replace pixel with centroid
```

Example:

```text
Original:

[250, 10, 15]

Nearest centroid:

[245, 12, 18]

Compressed:

[245, 12, 18]
```

This process is repeated for all pixels.

---

# ⚡ Optimization

Running K-Means on every pixel of a large image can be computationally expensive.

Therefore, this project uses **pixel sampling during K-Means training**.

Instead of training on every pixel:

```text
1,000,000 pixels
       ↓
Random sample
       ↓
10,000 pixels
       ↓
K-Means training
```

After the representative colors are learned, the centroids are applied to the complete image.

This improves processing efficiency for large images.

# 📈 Elbow Method

The project also includes an **Elbow Method** to analyze different values of K.

The following values can be evaluated:

```text
K = 2
K = 4
K = 8
K = 16
K = 32
K = 64
```

For every K, the K-Means **inertia** is calculated.

The result is visualized as a graph:

```text
Inertia
   │
   │\
   │ \
   │  \
   │   \
   │    \__
   │       \____
   │
   └──────────────────
      K
```

The elbow region can help identify a reasonable number of clusters where increasing K further provides diminishing improvement in clustering error.

# 📊 Evaluation Metrics

The project evaluates the compressed image using multiple metrics.

## 1. MSE — Mean Squared Error

MSE measures the average squared difference between the original and compressed images.

```text
Lower MSE → Less reconstruction error
```

Formula:

```text
MSE = 1/N Σ(original - compressed)²
```

---

## 2. PSNR — Peak Signal-to-Noise Ratio

PSNR measures the quality of the reconstructed image relative to the original.

```text
Higher PSNR → Better image quality
```

The value is represented in decibels:

```text
PSNR = 10 log10(MAX² / MSE)
```

---

## 3. SSIM — Structural Similarity Index

SSIM measures structural similarity between the original and compressed image.

Its value generally ranges from:

```text
0 → Low similarity
1 → Very high similarity
```
